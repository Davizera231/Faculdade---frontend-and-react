# Esteira de Propostas — Frontend

Interface React para o sistema de tramitação de propostas comerciais.

## Stack
- React 18 + Vite 5
- React Router DOM v6
- Axios
- Bootstrap 5.3
- React Toastify

## Como rodar
```bash
npm install
npm run dev   # http://localhost:3000
```
> Backend deve estar em http://localhost:8080/api
